This folder is for screenshots referenced by `schedule-overrides.md`.

Recommended filenames and purpose:

- `schedule_list_filters.png` — Admin Schedule list view with filters and checkboxes visible.
- `schedule_bulk_action_menu.png` — The Action dropdown open showing override actions.
- `schedule_change_form.png` — Schedule change form showing the informational banner and override fields.

Capture guidance:
- Use Windows `Win + Shift + S` to snip, paste into Paint or editor, save as PNG.
- Recommended width: ~1200px. Keep files under ~500KB if possible.
- Place files in this folder and commit. The runbook will reference them as `assets/<filename>`.
