# سامانهٔ مدیریت و کنداکتور برنامه‌های رادیویی و تلویزیونی

## مرحبا

سامانهٔ جامع و هوشمند برای مدیریت و کنداکتور خودکار برنامه‌های رادیویی و تلویزیونی

---

## ویژگی‌های اصلی

✅ **ساختار دیتابیسی حرفه‌ای** - ۱۶ مدل Django برای مدیریت کامل برنامه‌ها

✅ **اتوماسیون هوشمند** - سیستم کنداکتور خودکار برای پخش برنامه‌ها

✅ **مدیریت جامع** - پنل مدیریتی Django با رابط کاربری حرفه‌ای

✅ **ثبت‌های کامل** - تمامی اقدامات و تغییرات ثبت می‌شوند

✅ **تحلیل و آمار** - داده‌های تحلیلی برای هر برنامه

✅ **انعطاف‌پذیری** - امکان تعریف دستورالعمل‌های خاص برای هر برنامه

---

## شروع سریع

### نیازمندی‌ها
- Python 3.10+
- Django 5.2+
- SQLite (پیش‌فرض) یا پایگاه‌های داده دیگر

### نصب و راه‌اندازی

#### 1. محیط مجازی را فعال کنید
```bash
# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate
```

#### 2. وابستگی‌ها را نصب کنید
```bash
pip install -r requirements.txt
```

#### 3. مهاجرت‌های دیتابیس را اعمال کنید
```bash
python manage.py migrate
```

#### 4. سوپرکاربر را ایجاد کنید
```bash
python manage.py createsuperuser
```

#### 5. سرور توسعه را شروع کنید
```bash
python manage.py runserver
```

سپس به آدرس `http://localhost:8000/admin/` رفته و وارد شوید.

## معماری دیتابیس

سامانه ۱۶ مدل Django را شامل می‌شود که به ۵ بخش تقسیم می‌شوند:

### بخش 1: اطلاعات مرجع (پایه)
- **Channel**: شبکه‌ها و ایستگاه‌های پخش
- **Genre**: ژانرهای برنامه
- **Role**: نقش‌های افراد (تهیه‌کننده، مجری، ...)
- **Person**: افراد
- **TargetAudience**: مخاطبین هدف براساس سن

### بخش 2: برنامه‌ها (ورود اولیه)
- **Program**: برنامهٔ اصلی (اطلاعات ثابت)
- **ProgramMember**: اعضای هر برنامه

### بخش 3: نمونه‌های برنامه (برای هر پخش)
- **ProgramInstance**: نمونهٔ برنامه برای هر روز/ساعت
- **ProgramGuest**: مهمانان هر نمونه
- **ProgramAsset**: فایل‌های صوتی/تصویری

### بخش 4: ویرایش و تاریخچه
- **ProgramVersion**: نسخه‌های برنامه
- **ScheduleModification**: تعدیلات برنامه‌ریزی

### بخش 5: مدیریت و کنترل
- **Schedule**: برنامه‌ریزی نهایی
- **Conductor**: کنداکتور (دستورالعمل‌های خودکار)
- **ConductorLog**: ثبت‌های کنداکتور
- **AnalyticsData**: آمار و تحلیل

**برای جزئیات بیشتر به فایل `DATABASE_ARCHITECTURE.md` رجوع کنید.**

## جریان استفاده

### مرحله 1: تعریف داده‌های مرجع
در بخش Admin:
1. شبکه‌ها (Channels) را تعریف کنید
2. ژانرها (Genres) را تعریف کنید
3. نقش‌ها (Roles) را تعریف کنید
4. افراد (Persons) را ثبت کنید
5. مخاطبین هدف (Target Audiences) را تعریف کنید

### مرحله 2: ورود برنامه‌ها
1. برنامهٔ جدید (Program) ایجاد کنید
2. اعضای برنامه (Program Members) را اختصاص دهید
3. ژانرها و مخاطبین هدف را انتخاب کنید

### مرحله 3: برنامه‌ریزی برای پخش
1. نمونهٔ برنامه (Program Instance) ایجاد کنید
2. مهمانان (Program Guests) را اضافه کنید
3. فایل‌ها (Program Assets) را بارگذاری کنید
4. زمان‌بندی (Schedule) ایجاد کنید

### مرحله 4: تنظیم کنداکتور
1. Conductor را تعریف کنید
2. دستورالعمل‌های خودکار را فعال/غیرفعال کنید
3. برنامهٔ جایگزین (در صورت نیاز) تعیین کنید

### مرحله 5: پخش و نظارت
1. کنداکتور اقدامات خودکار را انجام می‌دهد
2. ثبت‌های کنداکتور (Conductor Logs) ذخیره می‌شوند
3. آمار (Analytics) جمع‌آوری می‌شوند

## پنل مدیریت

پنل مدیریت Django Admin طوری پیکربندی شده است که:

- ✅ **رابط کاملاً فارسی** - تمامی برچسب‌ها و توضیحات به فارسی هستند
- ✅ **سازمان‌بندی مناسب** - بخش‌ها منطقی و مرتب هستند
- ✅ **جستجو و فیلتر** - امکان جستجو و فیلترکردن دقیق
- ✅ **درج‌های درون‌صفحه** - ویرایش روابط مستقیماً در صفحه
